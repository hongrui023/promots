# 同步配置指南

先把三件事说清楚，避免白折腾。

## 一、你指定的两个网盘，实际情况是这样

### 腾讯微云 —— 开放 API 已不对个人开放 ⚠️

网上能搜到的微云 API 是 `graph.qq.com/weiyun/*`，那是 2013 年微信/Qzone 开放平台时代的东西，走 QQ 互联的 OAuth。**现在已不再向个人开发者发放接口权限**，文档也基本下架了。

微云官方目前支持的跨端同步方式是 **「微云同步助手」**：在电脑上装同步助手，指定一个本地文件夹与云端绑定，之后这个文件夹里的改动会自动上云，另一台电脑装同步助手后就能拿到同样内容。

**所以微云的可行路径是：把应用的数据文件放进微云同步助手的文件夹。** 对应本项目的「本地同步文件夹」通道。

限制：微云 Android 客户端**没有同步盘功能**，所以这条路只能打通 Windows ↔ Windows。手机端要同步，请用 Gist 或 WebDAV。

### 百度网盘 —— 个人开发者可以用 ✅

百度网盘开放平台（<https://pan.baidu.com/union/home>）对个人开放：
- 实名认证（个人身份证即可）→ **即刻审核通过**
- 个人开发者可创建 **2 个应用**
- 基础能力包含：获取网盘状态与文件信息、上传、下载、管理文件 —— 正是我们需要的能力
- 分享功能需要企业认证且付费，但我们不需要分享

Access Token 有效期 **30 天**，过期可用 Refresh Token 续期。

限制：手机浏览器上调用 `d.pcs.baidu.com` 上传会被跨域策略拦截，**建议在桌面端使用本通道**。

## 二、五条路怎么选

| 通道 | 适用 | 申请成本 | 手机可用 |
|---|---|---|---|
| **GitHub Gist** | 最省事，两端一致 | 一个 Token，2 分钟 | ✅ |
| **本地同步文件夹** | Windows 日常主力 | 无 | ❌ |
| **WebDAV** | 想在手机上也用网盘 | 注册坚果云 | ✅ |
| **百度网盘** | 已经在用百度网盘 | 实名后 2 分钟 | ⚠️ |
| **手动导入导出** | 应急备份 | 无 | ✅ |

**建议组合**：Windows 上用「本地同步文件夹」+ 微云同步助手；手机和跨设备用「GitHub Gist」。两个通道可以先后切换使用，数据格式一致，不会冲突。

## 三、GitHub Gist（推荐）

### 1. 申请 Token

打开这个链接，会直接带上正确的权限勾选：

<https://github.com/settings/tokens/new?scopes=gist&description=AI-Prompt-Hub>

- Note 随便填（例如 `AI-Prompt-Hub 同步`）
- Expiration：建议选 90 天或自定义长期，到期后重新生成即可
- **Scopes 只勾 `gist`** —— 不要勾 `repo`，这个应用不需要读写你的代码仓库
- 点 Generate token，**复制那串 `ghp_...`**（页面关掉就再也看不到了）

> 用独立 Token 的好处：哪天想停用，直接吊销这一个 Token，不影响其他东西。

### 2. 在应用里配置

设置 → 同步 → 选「GitHub Gist（推荐）」→ 填入 Token → 勾选「创建为私有 Gist」→ 点「测试连接」。

- 如果是**第一台设备**：测试会提示"尚未创建数据 Gist"，直接点「立即双向同步」，会自动创建，并把 Gist ID 回填到配置里。
- 如果是**第二台设备**：把第一台设备上显示的 **Gist ID** 填进去（测试连接也会自动识别到你账号下已有的数据 Gist），然后同步即可。

## 四、本地同步文件夹 + 微云同步助手（Windows 推荐）

### 1. 装并配置微云同步助手

1. 下载安装 [微云同步助手](https://www.weiyun.com/download)，用你的微云账号登录；
2. 在同步助手里新建一个同步文件夹，例如 `D:\微云同步助手\AI-PromptHub`；
3. 等它显示同步完成（首次可能较慢）。

> 用百度网盘同理：开通「同步空间」，把文件夹放进同步空间目录。

### 2. 在应用里配置

设置 → 同步 → 选「本地同步文件夹」→ 点「📁 选择同步目录」→ 选中上面那个文件夹。

- **网页端**：用浏览器的目录选择器授权。授权句柄会存在 IndexedDB 里，下次打开不用重新选（如果浏览器重新询问权限，点「允许」即可）。
- **桌面端**：有两种模式——「浏览器目录选择器」或「手动填写绝对路径」。桌面端建议用目录选择器，选完会自动填好路径。

之后点「测试连接」确认目录可写，再点「立即双向同步」。

**在第二台电脑上**：同样装微云同步助手、绑定同一个云端的同步文件夹，然后在应用里选同一个本地目录即可。微云负责把 JSON 搬过去，应用负责合并。

### 注意

- 数据文件名默认 `ai-prompt-hub.json`，两台设备必须一致（改了要一起改）；
- 不要把同步目录指向系统目录或桌面根目录，避免误操作；
- 微云免费空间 10 GB，这个 JSON 通常只有几十 KB，完全够用。

## 五、WebDAV（手机端也能用网盘）

以坚果云为例：

### 1. 获取应用密码

1. 登录 [坚果云](https://www.jianguoyun.com/)；
2. 右上角头像 → 账户信息 → **安全选项** → 第三方应用管理 → **添加应用密码**；
3. 名字随便填（例如 `AI-Prompt-Hub`），生成后**记下这串密码**。

> 这里必须用**应用密码**，不是你的登录密码。坚果云主密码不支持 WebDAV。

### 2. 在应用里配置

设置 → 同步 → 选「WebDAV」：

| 字段 | 填什么 |
|---|---|
| 文件完整地址 | `https://dav.jianguoyun.com/dav/AI-PromptHub/ai-prompt-hub.json` |
| 用户名 | 你的坚果云登录邮箱 |
| 密码 | 上一步生成的应用密码 |

点「测试连接」。返回 404 是正常的（文件还没创建），第一次同步时会自动建目录和文件。

> 其他服务商同理：Nextcloud 用 `https://你的域名/remote.php/dav/files/用户名/路径/文件.json`；群晖用 `http://IP:5005/路径/文件.json`。
>
> 部分 WebDAV 服务商不返回跨域头，浏览器端（含 PWA）可能连不上。如果遇到 `请求被浏览器跨域策略（CORS）拦截`，改用桌面端，或换 Gist。

## 六、百度网盘

### 1. 注册开发者并创建应用

1. 打开 <https://pan.baidu.com/union/home>，用百度账号登录；
2. 点右上角「控制台」→ 完成**实名认证**（个人身份证 + 手机号，即刻通过）；
3. 点「创建应用」：
   - 应用类型选 **「软件」**（不要选硬件）
   - 应用名称随意，例如 `AI Prompt Hub`
4. 创建完成后在应用详情里拿到三样东西：

| 凭证 | 长什么样 | 用途 |
|---|---|---|
| **AppID** | 纯数字，如 `124176126` | 拼授权链接时作为 `device_id` |
| **AppKey** | 字母数字混合 | 授权链接里的 `client_id`（**相当于账号**） |
| **SecretKey** | 字母数字混合 | 刷新 Token 用（**相当于密码，别外泄**） |

### 2. 配置回调地址（最容易踩的坑）

1. 进入应用详情页 → **安全设置**；
2. 点蓝色按钮「**添加 OAuth 授权回调页地址**」；
3. 填入，必须与下面完全一致：

   ```
   http://127.0.0.1:5180/oauth-callback.html
   ```

4. 保存后**等 1–2 分钟**生效（百度后台有缓存）。

> ⚠️ 只在「全局回调地址」框里填是不够的，**必须点那个按钮单独加一条**，否则授权时会报 `unknown client id`。
>
> ⚠️ 桌面端会固定占用 5180 端口。如果你同时开着 `npm run serve`，桌面端会退到随机端口，回调地址就对不上了——跑授权时把 `npm run serve` 关掉。

### 3. 在应用里授权

设置 → 同步 → 选「百度网盘（进阶）」，填写：

- AppKey、SecretKey、AppID（纯数字那个）
- 云端存放路径：默认 `/apps/AI-Prompt-Hub/ai-prompt-hub.json`
  **必须以 `/apps/你的应用名/` 开头**，这是开放平台的沙箱限制，别改成 `/我的文档/...`

点「🔑 获取授权」→ 浏览器打开百度授权页 → 登录并点「同意授权」→ 会自动跳转到回调页，Token 自动回填到设置里。

如果自动回填失败（比如浏览器拦截了跳转），回调页上有一串 Token，点「复制 Token（手动粘贴用）」，回到设置页粘进 Access Token 字段即可。

Token 有效期 30 天。过期后点「刷新 Token」即可续期；如果 Refresh Token 也失效了，重新走一次授权。

### 4. 验证

点「测试连接」，应该显示「已授权，账号：你的百度昵称」。

## 七、手动导入导出（兜底）

永远可用的方案：设置 → 数据 → 「⤓ 导出全部为 JSON」，把文件丢进任意网盘。换设备时下载下来，「⤒ 从 JSON 导入」选合并模式。

导入是**按记录合并**的：同一条指令以修改时间较新的为准，不会一股脑覆盖你本机的新内容。所以可以放心导入旧备份。

也可以「📋 复制为 Markdown」把整个指令库按分类整理成一份文档，直接贴进 Notion、飞书、语雀。

## 八、同步是怎么合并的

理解这个机制能帮你判断"数据会不会丢"。

**取回云端快照 → 逐条比对 → 写回本地 → 上传合并结果。**

逐条比对规则：

1. **同一 id**：`updatedAt`（最后修改时间）较新的胜出。两台设备各改**不同**的指令时，两条修改都会保留。
2. **使用次数**：取两端**最大值**而不是较新值。因为在两端各用过几次是真实发生的事实，不该因为同步而回退。
3. **一方没有**：直接采用另一方。
4. **时间戳完全相同**：保守取本地。

删除的处理：删除是**软删除 + 墓碑**。删掉的指令会带着 `deleted: true` 和删除时间一起同步出去，另一台设备收到后也标记为删除。否则你在一台设备上删掉的东西，会被另一台设备的旧数据"复活"。

**会丢数据的情况**：两台设备**同时**编辑**同一条**指令的**不同字段**——较晚保存的那台整体胜出，另一台那次的改动会丢。这在单人使用场景下概率极低，且丢的只是一次编辑，不会损坏整个库。

自动同步默认开启：本地改动后延迟 8 秒上传（防抖，避免连续编辑时反复请求）；切回应用且距上次同步超过 1 分钟时拉取一次；另有定时双向同步（默认 15 分钟）。

## 九、排错

| 现象 | 原因与处理 |
|---|---|
| `请求被浏览器跨域策略（CORS）拦截` | 该服务不返回跨域头。改用桌面端，或换 Gist / WebDAV |
| Gist 报 `401` | Token 无效或过期。重新生成，注意只勾 `gist` 权限 |
| Gist 更新报 `404` | Gist ID 填错，或该 Token 无权访问这个 Gist |
| 百度报 `unknown client id` | 回调地址没单独点按钮添加，或还没过缓存期 |
| 百度接口返回 `errno: 111` | Access Token 失效，点「刷新 Token」或重新授权 |
| 百度上传失败，路径报错 | `remotePath` 必须以 `/apps/应用名/` 开头 |
| WebDAV 报 `401/403` | 用了登录密码而不是应用密码（坚果云） |
| 同步成功但另一台设备数据没变 | 检查两台的数据文件名 / 远端路径是否一致 |
| 手机上「本地同步文件夹」是灰的 | Android 浏览器不支持目录选择 API，属预期。换 Gist / WebDAV |
| 卸载 Android 应用后数据没了 | IndexedDB 随应用卸载清除。卸载前先同步或导出 JSON |

## 十、安全提示

- 同步文件是**明文 JSON**，包含你的全部指令。放**私有** Gist / 网盘私有目录。
- API Key（大模型、GitHub Token、百度 SecretKey）**只保存在本机**，且不包含在同步数据里。换设备需要重新填。
- 别把同步用的 Token 提交进 Git 仓库。项目 `.gitignore` 已排除常见凭据文件，但仍请自行留意。
- 桌面端只监听 `127.0.0.1`，不对局域网暴露。
