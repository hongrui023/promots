--------------------------------------------------------------------------------
■ 0  使用说明
--------------------------------------------------------------------------------

1. 每个模板都能整段复制到对话框，把【】里的内容换成你自己的信息即可。
2. 材料优先给本地绝对路径（如 D:\papers\chi.pdf），比粘贴正文更准、更省 token。
3. 一定写清"输出目录"。不写的话产物容易散落到临时目录里找不到。
4. 一条指令只做一件事；要多步连着做，用第 4 节的组合流程。
5. 想强制指定技能，就在句子里点名，例如"使用 nature-reader，把……"。
6. 技能名一律用英文：nature-reader / nature-writing / nature-figure ……

--------------------------------------------------------------------------------
■ 1  通用前缀（建议粘在每条指令最前面，可按需删减）
--------------------------------------------------------------------------------

按 skills 目录里对应技能的 SKILL.md 执行，并遵守以下纪律：

- 先读技能文件再动手，不要凭记忆套模板；需要 references / static 片段时按 manifest 加载。
- 只用我给的材料和我确认过的事实；缺信息先列【待确认清单】，不要猜测或补编。
- 引用、DOI、页码、统计量一律保留来源锚点；查不到就写"未核实"，禁止编造文献和数据。
- 产物统一写到【输出目录】，文件名与结构按技能约定；改动过的稿子另存新文件，不覆盖原件。
- 完成后回报四件事：用了哪个技能、读了哪些来源、生成了哪些文件、还有哪些不确定项。

■ 3  单技能指令模板
--------------------------------------------------------------------------------

【3.1】读论文：中英对照全文
技能：nature-reader
需要你替换：【论文路径/DOI】【输出目录】
--------------------------------------------------------------------------------
使用 nature-reader，把【论文路径或 DOI】做成图文对应的中英文对照 Markdown 阅读材料。
要求：
1. 每段保留英文原文，紧跟中文翻译；图表放在首次实质性讨论处，并翻译图注。
2. 每个段落、图、表、公式给出页码或来源锚点；公式用 Markdown 数学块并编号。
3. 扫描件或无法可靠转写的公式保留原图裁剪，不要用猜测的 LaTeX 替代。
4. 输出到【输出目录】，包含 paper.md、source_map.json、translation_notes.md、assets/。
5. 翻译备注里列出术语表、无法确认的内容和建议人工复核的地方。

--------------------------------------------------------------------------------
【3.2】精读一篇论文（Paper Card）
技能：nature-paper-card
需要你替换：【论文路径】【输出目录】
--------------------------------------------------------------------------------
使用 nature-paper-card 精读【论文路径】，生成完整的 01-16 节 Paper Card。
要求：
1. 先建立证据清单和 claim-evidence matrix，再写正文；每条结论绑定图、表、公式或实验。
2. 明确区分：作者陈述、外部事实、你的分析、研究假设，四类不要混在一起。
3. 单独说明：这篇论文真正证明了什么、没有证明什么、哪些结论是过度外推。
4. 末尾给出 3-5 个可证伪、可执行的后续研究想法，并写清验证所需实验。
5. 输出到【输出目录】；只在摘要或局部材料可用时，请显式标注"无法判断"的部分。

--------------------------------------------------------------------------------
【3.3】论文 → 中文汇报 PPT
技能：nature-paper2ppt
需要你替换：【论文路径】【页数】【听众】【输出目录】
--------------------------------------------------------------------------------
使用 nature-paper2ppt，把【论文路径】做成【12】页中文组会汇报 PPT。
听众背景：【材料/化学方向研究生，熟悉基本表征手段】
要求：
1. 不要照搬原文章节，按"研究问题 → 关键 claim → 核心证据 → 局限 → 可复用价值"重组。
2. 每页保留原图或原图裁剪，并标注来源（Figure 编号 + 页码）。
3. 每页给出标题、要点、takeaway；需要讲稿时补 speaker notes。
4. 密集图版允许拆分或裁剪，但不要重画数据；不要出现我无法核对的数值。
5. 输出到【输出目录】，交付可编辑 .pptx，并附图表资产清单和包体检查结果。

--------------------------------------------------------------------------------
【3.5】润色 / 翻译 / 精简
技能：nature-polishing
需要你替换：【目标期刊】【文本或文件路径】【输出目录】
--------------------------------------------------------------------------------
使用 nature-polishing，把【文件路径或以下段落】改成符合【Nature / Nature Communications / NMI】风格的英文。
要求：
1. 保持原有学术含义、数值、术语和证据边界，不新增结论、不弱化必要的限定。
2. 按沙漏结构理顺段落推进，去掉 AI 味、夸张因果和冗余修饰。
3. 输出三部分：修改后正文、主要修改点及理由、需要我确认的疑点。
4. 术语与单位保持一致；同一概念不要换词表达。
5. 结果写到【输出目录】，另存新文件，不要覆盖我的原稿。

--------------------------------------------------------------------------------
【3.15】科研配图 / 多面板图 / 机制图
技能：nature-figure
需要你替换：【数据与图件目标】【输出目录】
--------------------------------------------------------------------------------
使用 nature-figure，根据【数据文件 / 图注 / 结论】生成投稿级图件。后端用【Python / R】。
这张图要证明的核心结论：【一句话】
要求：
1. 先给图件契约（核心结论、证据层级、每个 panel 的证据角色、数据来源），我确认后再画。
2. 一张 Figure 回答一个 Results 级问题；主证据、control、正交验证、边界各司其职，
   不要用同一结果换指标凑 panel。
3. 明确尺寸、字体、字号、配色、分辨率与矢量导出格式；图注按目标期刊字数上限。
4. 保留全部观测，任何数据排除都要记录规则和前后计数。
5. 导出 PDF/SVG + 可复现脚本 + source data，并给出渲染碰撞/对齐检查结果。输出到【输出目录】。

【3.20】合法下载全文与 SI
技能：nature-downloader
需要你替换：【文献标识】【是否要 SI】【输出目录】
--------------------------------------------------------------------------------
使用 nature-downloader，下载【DOI / 题名 / CNKI 文献】的全文。
是否需要补充材料（SI）：【需要 / 不需要】
要求：
1. 按语言与出版商选择合法路线：中文走 CNKI 机构授权；英文优先出版商 API，
   失败再降级 PMC → Unpaywall → 出版商 OA / 合法仓储 → 机构授权。
2. 不绕过付费墙、DRM、验证码或双重认证，不读取浏览器 cookie、密码或 session 文件。
3. 输出时记录访问路径、失败原因和可复用配置，便于后续批量下载。
4. 保存到【输出目录】，并回报每篇的获取状态（成功/失败/原因）。

■ 4  组合工作流（一条龙，直接整段复制）
--------------------------------------------------------------------------------

【4.1】投稿前冲刺（读 → 审 → 补 → 改）
--------------------------------------------------------------------------------
按顺序完成下面 5 步，每步产物写到【输出目录】，全部用绝对路径。
材料：论文【PDF 路径】，目标期刊【Nature / NC / NMI】。
1) 用 nature-paper-card 精读全文，输出 claim-evidence matrix，标出证据薄弱处。
2) 用 nature-reviewer 生成三份互盲 reviewer report 和一份综合判断（只评审，不写回复）。
3) 用 nature-statistics 审查统计报告，列出必须补的 n、误差、检验与多重比较说明。
4) 用 nature-citation 给 Introduction 和 Discussion 的关键判断补 CNS 支撑文献（导出 RIS）。
5) 用 nature-response 把第 2、3 步的意见整理成"修回行动清单"（要补的实验、要改的文本、要加的引用）。
每步开始前先告诉我你打算怎么做，做完给我一句话结论和文件清单，再进入下一步。

--------------------------------------------------------------------------------
【4.2】组会 / 文献汇报流水线（读 → 卡 → PPT）
--------------------------------------------------------------------------------
材料：论文【PDF 路径】。输出目录：【……】。
1) 用 nature-reader 生成中英对照 reader，图表放在对应讨论处，保留来源锚点。
2) 用 nature-paper-card 生成精读卡，重点讲方法逻辑与实验—结论证据链。
3) 用 nature-paper2ppt 生成【12】页中文组会 PPT，图件取自第 1 步的 assets，
   每页标注来源 Figure 编号，附 speaker notes。
4) 最后给我一页"汇报要点备忘"：三个核心 takeaway、一个被攻击点、一个延伸想法。

--------------------------------------------------------------------------------
【4.5】新方向快速调研
--------------------------------------------------------------------------------
主题：【……】。输出目录：【……】。
1) 用 nature-academic-search 检索近 5 年文献并去重，输出带 DOI 的候选清单（20-30 篇）。
2) 选 5 篇最相关的用 nature-reader 或 nature-paper-card 做精读，输出方法对比表。
3) 汇总：领域共识、争议点、未被解决的问题、可能的技术路线，每条附来源。
4) 需要持续跟踪时，用 nature-literature-pipeline 建一条【每周】推送管线。

■ 5  占位符与常用约束句
--------------------------------------------------------------------------------

常用占位符
  【论文路径】        文件绝对路径，例如 D:\papers\chi_2026.pdf
  【输出目录】        例如 D:\codx projeeect\codex for work\out
  【目标期刊】        Nature / Nature Communications / NMI / 其他（会影响字数、display 数量等硬约束）

常用约束句（挑需要的加）
  - 只用我提供的材料，缺信息列【待确认清单】，不要猜。
  - 不要编造引用、DOI、页码或数值；查不到就写"未核实"。
  - 保留原始数值、术语和证据边界，不要加强结论。
